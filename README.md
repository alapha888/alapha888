MIT, single-file Python, stdlib only; [the 22 toolset differences, explained](https://gist.github.com/alapha888/4cd8ba942194f34609cb3b3c41862fce).
- **[Web Highlighter](https://microsoftedge.microsoft.com/addons/detail/highlighter/ooocjgnapglfljdgojdoacjdedpaplhe)** — Local-first browser extension for multi-color highlighting and inline annotation of web pages, with Weava CSV import and export to JSON, CSV, and Markdown. Live on Microsoft Edge Add-ons; [project site](https://alapha888.github.io/web-highlighter-site/); [watch the 51-second demo](https://youtu.be/WjfKIE33Pwg).
- **[MD Publisher](https://microsoftedge.microsoft.com/addons/detail/md-%E6%8E%92%E7%89%88%E5%8A%A9%E6%89%8B/ggimifkpgpbnpempalpkmnnlplklgkdi)** — Browser-based Markdown formatting tool (built on doocs/md) that converts a single Markdown document into platform-ready output for WeChat Official Accounts, Zhihu, and Juejin.
